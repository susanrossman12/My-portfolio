# assets/

Put your files here:

- **`susan-rossman-resume.pdf`** — your résumé. The site links to this path from
  the nav, the About section and the Contact section. If you name the file
  differently, update those links in `index.html` (search for `RESUME LINK`).
- **`portrait.jpg`** — a roughly square photo of you for the About section. Until
  you add one, the site shows your initials in a coloured tile.

Keep image files reasonably small (a portrait around 600–800px square is plenty)
so the page stays fast.
